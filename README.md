# Python Cloud Native Authenticator Module

Base inicial da plataforma de identidade e acesso cloud-native, preparada para
Python 3.13+ e FastAPI. A documentação do projeto está em [`4dev/`](4dev/README.md)
e a proposta de DDD estratégico em [`docs/architecture/`](docs/architecture/README.md).
A estratégia de entrega está em [`docs/devops/`](docs/devops/devops-strategy.md);
novas decisões arquiteturais podem partir do [template de ADR](docs/adr/ADR000-template.md).
