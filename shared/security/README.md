# Segurança compartilhada

Reservado a convenções e capacidades técnicas transversais alinhadas a Zero
Trust, menor privilégio, isolamento de tenant e Security by Design.

Não adicionar segredos, configuração sensível, políticas de domínio ou código
que contorne o proprietário de um bounded context. Identidade de tenant deve
vir de contexto validado no servidor. Nenhuma primitiva de segurança é
implementada nesta fundação.
