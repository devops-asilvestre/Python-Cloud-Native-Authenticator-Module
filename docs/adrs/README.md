# Índice de ADRs

As decisões arquiteturais oficiais existentes estão em [`../adr/`](../adr/),
que foi preservado sem movimentação. Use o [template de ADR](../adr/ADR000-template.md)
para novas decisões e atualize esse índice se decisões forem adicionadas.

Esta pasta fornece o ponto de navegação da estrutura arquitetural solicitada;
não duplica nem substitui documentos preexistentes.
