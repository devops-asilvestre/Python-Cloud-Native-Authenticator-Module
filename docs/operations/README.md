# Operações

Área reservada a runbooks, observabilidade operacional, resposta a incidentes,
recuperação e objetivos de serviço. Documentos operacionais devem identificar
escopo, pré-requisitos, impacto e validação, e nunca incluir segredos.

O ambiente de dependências local está descrito em
[`../../infrastructure/docker/README.md`](../../infrastructure/docker/README.md).
Não há runbooks de produção nesta fundação.

Os guias para iniciar e diagnosticar a plataforma local estão em
[`../../LOCAL_DEVELOPMENT.md`](../../LOCAL_DEVELOPMENT.md) e
[`../../LOCAL_TROUBLESHOOTING.md`](../../LOCAL_TROUBLESHOOTING.md).
