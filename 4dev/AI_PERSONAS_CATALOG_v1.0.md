## Objetivo

Este catálogo define todas as personas oficiais da plataforma.

Cada persona pode ser ativada individualmente ou em conjunto dentro dos
prompts estruturados.

Todas as personas devem seguir:

• DDD
• Clean Architecture
• SOLID
• Security By Design
• Cloud Native Design
• DevSecOps
• LGPD
• Observability First
